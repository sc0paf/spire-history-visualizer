# spire-history-visualizer

Save the page to some folder

Make a copy of your /history/ folder ( in game ` to open cmd pallette, 'open saves' duplicate folder, copy somewhere)

Right click page -> Open in browser

Use file picker to select your duplicated history folder

You can probably use your main folder if you're lazy but dont be mad at me if you somehow brick your saves

the filepicker is just bc browsers don't allow arbitrary file access without prompting.
